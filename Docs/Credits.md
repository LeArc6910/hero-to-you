# 외부 에셋과 출처

게임의 그림과 소리는 대부분 이 저장소에서 만들었다(글자 줄 도트 그림, 코드로 합성한 소리). 2026-11-11부터 사용자 결정으로 무료 공개 에셋도 쓴다: **CC0(퍼블릭 도메인)를 먼저**, 출처 표시가 조건인 CC-BY는 아래에 정확히 적고 쓴다. CC-BY-SA·비상업(NC)·변경 금지(ND)·"개인용 무료"는 쓰지 않는다. 생성형 AI 결과물은 모델의 이용 조건이 상업 이용을 허락할 때만 쓰고 모델과 조건을 적는다.

새 에셋을 들일 때 이 문서에 한 줄을 더한다(무엇에 썼는지, 원본 제목, 만든 이, 라이선스, 주소, 고친 것).

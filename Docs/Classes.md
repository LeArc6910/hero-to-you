## M5 직업 초안

- **도적**: 찌르기(민첩 2, 지연 70%), 그림자 숨기(다음 공격 전까지 대상이 되지 않음), 급소 찌르기(연계를 모두 써서 그만큼 주사위 +). 첫 라운드 선공 판정
- **음유시인**: 불협화음(매력 2, 약화), 노래 바꾸기(용기: 아군 확률 +10 / 안식: 매 라운드 회복 3 / 박자: 지연 −15%), 앙코르(아군 하나를 순서표 맨 앞으로)
- **연금술사**: 투척 폭탄(지능 3, 모든 적), 산성 병(방어도 −2), 즉석 물약(재료 1로 회복). 지도에서 재료 칸
- **사령술사**: 생명 흡수(의지 3, 흡혈), 해골 일으키기(영혼 2, 해골은 대신 맞는 유닛), 죽음의 표(대상이 쓰러지면 영혼 +2), 피의 대가(생명력 5로 주사위 +2)
- **점성술사**: 별똥별(지능 2), 운명 바꾸기(아군 하나를 앞당기고 적 하나를 늦춤), 예언(다음 주사위 5개를 보이고 적 의도의 확률 −15)
- **야수조련사**: 협공 명령(조련사와 늑대가 같은 적을 친다 = 협공 자동), 지켜라(늑대가 아군 대신 맞음), 야성의 부름(늑대 강화). 늑대는 자기 차례가 있고 쓰러지면 쉼터에서 돌아온다
